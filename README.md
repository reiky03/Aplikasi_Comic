## ⚡ Tentang Kizen

Kizen adalah proyek pribadi open source yang dibuat untuk kenyamanan membaca komik favorit secara mandiri tanpa gangguan iklan pop-up, situs web yang sering berganti domain, atau aplikasi komik lain yang terlalu berat dan penuh bloatware.

---

## ✨ Fitur Utama

- 🛡️ **VPN Bawaan Anti-Blokir**: Membuka web komik yang terblokir secara instan langsung dari layar bacaan tanpa perlu aplikasi VPN luar, dan tetap aktif berjalan di background.
- 📜 **Reader Nyaman (Webtoon & Manga)**: Mendukung scroll vertikal super mulus untuk manhwa/webtoon serta mode per-halaman untuk manga, lengkap dengan bookmark chapter yang stabil.
- 📚 **Library & Navigasi Koleksi**: Mengelompokkan komik ke berbagai koleksi, berpindah tab koleksi dengan gestur swipe kiri/kanan, dan mengurutkan komik berdasarkan pembaruan bab terbaru.
- 🧩 **Dukungan Ekstensi & Web Fleksibel**: Mendukung integrasi repositori ekstensi (ala Mihon/Tachiyomi) serta penambahan tautan website komik kustom secara otomatis.
- 🔓 **Engine Bypass Cloudflare**: Dilengkapi penanganan sesi browser dan decryptor otomatis untuk website komik yang memiliki proteksi Cloudflare Turnstile.
- ☁️ **Login Google & Cloud Sync**: Menyimpan seluruh koleksi library dan riwayat bacaan ke cloud Firebase sehingga aman saat berganti perangkat.
- 🔄 **Pembaruan Otomatis In-App**: Mengecek dan mengunduh versi aplikasi terbaru langsung dari menu Pengaturan tanpa harus membuka browser manual.
- 🌓 **Antarmuka Dark Modern**: Tampilan bertema gelap yang elegan, bersih, nyaman di mata saat maraton malam hari, dan hemat konsumsi baterai.
