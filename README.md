### ✨ Fitur Utama

- 🛡️ **VPN Anti-Blokir**: Buka web komik terblokir langsung dari dalam aplikasi.
- 📜 **Reader Nyaman**: Mode webtoon vertikal & mode manga per-halaman.
- 📚 **Library & Koleksi**: Atur komik, swipe antar koleksi, dan cek update bab terbaru.
- 🧩 **Support Ekstensi**: Dukung repo ekstensi (ala Mihon) & tambah web kustom.
- ☁️ **Cloud Sync**: Sinkronisasi library & riwayat bacaan otomatis via akun Google.
